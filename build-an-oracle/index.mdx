An **Agentic Oracle** is an AI agent that owns a verifiable identity (an IXO entity DID), authenticates via UCAN delegation, stores conversations in encrypted per-user Matrix rooms, and composes its capabilities from typed plugins. **QiForge ships the runtime** ([`@ixo/oracle-runtime`](https://github.com/ixoworld/ixo-oracles-boilerplate/tree/main/packages/oracle-runtime)) — your oracle is a `main.ts` plus the plugins you want.

## What QiForge does for you

```ts
import { createOracleApp } from '@ixo/oracle-runtime';
import { MyPlugin } from './plugins/my-plugin/my-plugin.plugin.js';

const app = await createOracleApp({
  config: { name: 'My Oracle', org: 'Acme' },
  plugins: [new MyPlugin()],
});
await app.listen();
```

That's a working oracle. One call to [`createOracleApp`](/build-an-oracle/develop/create-oracle-app) and the framework gives you:

You ship the green box on top. The framework handles the rest.
